# AI-Based Career Recommendation System using ANN

## Project Overview

This project develops a **Career Recommendation System** using an **Artificial Neural Network (ANN)** to suggest suitable career paths for students based on their academic performance and skill set.

The system analyzes various student attributes such as mathematical ability, programming skills, communication skills, creativity, logical thinking, and interests to predict the most appropriate career.

---

## Features

*  Intelligent career prediction using ANN
*  Uses real-world dataset (Kaggle)
*  Model evaluation with multiple metrics
*  Real-time user input prediction
*  Visualization of model performance
